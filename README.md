# payroll-automation-framework

A portfolio project: a test automation framework built around a small payroll application.

| Path           | What                                                                 |
|----------------|----------------------------------------------------------------------|
| [`app/`](app)  | Demo payroll app (Express + TypeScript API, Postgres, web UI). See [app/README.md](app/README.md) |
| `tests/`       | Test automation framework (coming in later phases)                   |

## Quick start

```bash
cd app
docker compose up --build
```

Open http://localhost:3000 and log in as `admin` / `admin123`.
